Tally Timer サポート

Macのメニューバーで使うタイマーと完了回数カウンター。macOS 14（Sonoma）以降に対応しています。

タイマーの使い方

  1. Tally Timerを起動し、メニューバーの残り時間をクリックします。
  2. 操作パネルの「長さ」で1〜180分を選び、「開始」を押します。
  3. タイマーが終わると完了回数が1増えます。次のセットは、もう一度「開始」を押してください。

よくある質問

起動後、どこから操作できますか？

画面上部のメニューバーに残り時間と完了回数が表示されます。その表示をクリックすると操作パネルが開きます。

タイマーの完了通知が出ないときは？

macOSの「システム設定 → 通知 → Tally Timer」で通知を許可してください。通知を確認したいときは、「長さ」を1分に設定して試せます。

タイマーの長さを変更するには？

実行中は「一時停止」を押してから、「長さ」を変更してください。

完了回数の調整やリセットはできますか？

操作パネルの「＋」「−」で調整でき、「0 に戻す」を押すとリセットできます。タイマーの長さと完了回数は、アプリを終了してもMacに保存されます。
