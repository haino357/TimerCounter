Tally Timer プライバシーポリシー

制定日 2026年11月22日

保存するデータ

Tally Timer は、次回起動時に復元するため、タイマーの長さと完了回数をこのMacに保存します。開発者はアプリから利用者のデータを収集、送信、共有しません。アプリにアカウント登録、広告、利用状況の分析、トラッキングはありません。

通知

通知を許可すると、タイマーの完了時にmacOSがこのMacに通知を表示します。通知の許可は、macOSの「システム設定 → 通知」からいつでも変更できます。

データの保持と削除

タイマーの長さと完了回数は、設定を変更するか保存データを削除するまで、このMacに残ります。完了回数は操作パネルの「0 に戻す」でリセットできます。

Mac App Store版の保存データをすべて消す場合は、アプリを終了してから、Finderの「フォルダへ移動」で ~/Library/Containers/io.github.haino357.timercounter を開き、アプリのコンテナをゴミ箱に移動してください。GitHub Releasesのバージョン1.0.0で保存したデータの削除方法は、READMEの保存データの項目に記載しています。
